# 商談メモ for Google Meet

Google Meet の字幕を読み取り、**10分ごとに商談の要点をまとめ**、終了時に**議事録と次回の提案スライド（Google スライドで開ける .pptx）**を作ります。

- 要約には、Claude のプランに含まれている **Claude Code（`claude -p`）** を使います。API の追加費用はかかりません
- 音声認識には **Meet の字幕機能** を使います（無料）
- データはすべて自分の Mac に保存されます（`data/` フォルダ）

```
Google Meet の字幕 ──(Chrome拡張)──→ Mac上のローカルサーバー ──10分ごと──→ claude -p
                                              │                              │
                         Meet横のサイドパネルに表示 ←── 要約・認識合わせが必要な点・次に聞くこと
                                              │
                               商談終了ボタン → 議事録.md ＋ 提案スライド.pptx
```

## まとめの内容

**10分ごと（会議中）**
- この区間の要点
- 合意・決定事項
- **認識合わせが必要な点**（「〜という理解でよろしいでしょうか？」の形で、その場で確認できる）
- 宿題・ToDo、顧客の課題、次に聞くべきこと

**終了時**
- 議事録（お客様に送る確認メールの文案つき）
- 提案スライド（1枚目は前回の振り返り＝認識合わせ。表紙を除き 6〜9 枚、話す内容はスピーカーノートに記載）

## セットアップ（Mac・初回のみ）

### 1. 必要なもの
- [Node.js](https://nodejs.org/)（18 以上。LTS 版を推奨）
- [Claude Code](https://docs.claude.com/ja/docs/claude-code/overview)：ターミナルで `claude` を一度起動し、**Claude のアカウント（プラン）でログイン**してください
- Google Chrome

### 2. ダウンロードとインストール
```bash
git clone https://github.com/yoshiakinishida/arcra-marke.git
```
```bash
cd arcra-marke/server && npm install
```

### 3. 設定（任意）
```bash
cp .env.example .env
```
`.env` で要約の間隔・モデル・自社名・Google ドライブの保存先を変えられます。自社資料は `materials/` フォルダに置いてください（詳しくは `materials/_README.md`）。

### 4. Chrome 拡張機能を入れる
1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」で、`arcra-marke/extension` フォルダを選ぶ
4. ツールバーのパズルアイコンから「商談メモ for Google Meet」をピン留めする

## 毎回の使い方

1. ターミナルでサーバーを起動（商談中は開いたままにする）
   ```bash
   cd arcra-marke/server && npm start
   ```
2. Google Meet に参加し、**字幕（CC ボタン）をオン**にする。字幕の言語は「日本語」にする
   - 画面左下に「● 商談メモ: 記録中」と表示されれば記録できています
3. ツールバーの拡張機能アイコンをクリックすると、右側にサイドパネルが開く
   - 顧客名・メモ（商談の目的など）を入れると、要約と提案に反映されます
   - 10分ごとに自動でまとめが更新されます。「今すぐ要約」でも作れます
4. 商談が終わったら「商談終了 → 議事録・提案スライド作成」を押す（数分かかります）
5. 提案スライドを Google スライドで開く
   - `.env` の `DRIVE_DIR` を設定していれば、Google ドライブに自動で保存されます。ドライブ上で開き、「ファイル → Google スライドとして保存」を選んでください
   - 設定していない場合は、ダウンロードした .pptx を Google ドライブにアップロードして開いてください

### 対面（オフライン）の商談で使う場合
1. 自分だけで Meet の会議を開始し（`meet.new` など）、**マイクをオン**、字幕をオンにする
2. PC のマイクが室内の声を拾い、字幕になります
3. サイドパネルの「形式」を「対面（オフライン）」にする

字幕の話者名はすべて自分になるため、発言者は Claude が文脈から推測します（「（推定）」と表示）。PC は話す人の近くに置くか、外付けの会議用マイクを使うと精度が上がります。

## 保存されるファイル

`data/sessions/<日時>_<会議コード>/`
| ファイル | 内容 |
|---|---|
| `transcript.md` | 字幕の全文 |
| `summary-01.md` … | 10分ごとのまとめ |
| `minutes.md` | 議事録 |
| `proposal.json` / `proposal.pptx` | 提案スライドの内容とファイル |

## 注意点

- **録音・文字起こしすることは、必ず事前にお客様へ伝えてください**
- **利用枠**：1時間の商談で、要約 6 回＋議事録・提案 2〜3 回ほど `claude` を呼び出します。上限が気になる場合は `.env` で `SUMMARY_MODEL=haiku` にしてください
- **API の費用について**：環境変数 `ANTHROPIC_API_KEY` が設定されていると、Claude Code は API 課金で動きます。このサーバーは `claude` を呼び出すときに、この環境変数を自動で外します
- この方法は「自分の Mac で、自分のアカウントで使う」ためのものです。チームに展開する場合は、API 契約での運用に切り替えてください
- **Meet の画面が変わると字幕を読めなくなる**ことがあります。「字幕（CC）をオンにすると記録します」の表示が消えない場合は、`extension/content.js` の `SELECTORS` を修正してください
- サーバーは `127.0.0.1`（自分の Mac）からの接続しか受け付けません
