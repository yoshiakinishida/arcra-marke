# 自社資料フォルダ

このフォルダに置いた `.md` / `.txt` / `.csv` ファイルは、提案スライドを作るときに Claude が参照します。

- 例: `サービス概要.md`、`料金表.csv`、`導入事例.md`、`よくある質問.md`、`提案書の型.md`
- PDF や PowerPoint の資料は、テキストをコピーして `.md` で保存してください
- 合計 6 万文字までが読み込まれます（ファイル名の順）
- ファイル名が `_` で始まるもの（このファイルなど）は読み込まれません
- 顧客の情報や機密資料はここに置かず、自社の公開できる資料を中心にしてください

資料がない場合、提案スライドの具体的なサービス名や金額は【要確認】と表示されます。
